# Mise Platform Demo: Forge & Hearth Client Website

**Framing:** Experience how Mise’s AI-native design system transforms cooking-brand storytelling through seamless navigation, editorial depth, and visual hierarchy.

## 1. Homepage (index.html)
- **Hero Section:** Bold typography + vibrant imagery anchor brand identity; CTA buttons use micro-interactions for engagement.
- **About Section:** Clean layout highlights core values with minimal text, guiding users to blog for deeper content.
- **Teaser Grid:** Latest posts use card shadows and hover states to invite exploration without overwhelming the viewport.

**Navigation:** Scroll-based anchors link to blog index, prioritizing discovery over menu complexity.

## 2. Blog Index (blog.html)
- **Post Cards:** Three-column grid with consistent padding; titles use gradient text for visual emphasis.
- **Card Design:** Icon-based tags (e.g., 🍝) and recipe icons signal content type at a glance.
- **Call-to-Action:** 'View All Posts' button uses a subtle pulse animation to draw attention.

**Navigation:** Pagination buttons mirror the homepage’s design language for cohesive UX.

## 3. Blog Posts
### Lemon Garlic Pasta
- **Content Quality:** High-res food photography + structured recipe sections (Ingredients → Instructions → Tips).
- **Visuals:** Step-by-step diagrams reduce cognitive load; color-coded ingredients in the list.
- **Navigation:** Back button uses a 'floating action' design for easy access.

### Tomato Basil Soup
- **Content Quality:** Embedded video tutorial enhances instructional value; SEO-optimized metadata.
- **Design:** Hero image transitions smoothly into the recipe content block.
- **Navigation:** Related posts sidebar uses sticky positioning for context retention.

### Sheet-Pan Chicken
- **Content Quality:** Ingredient substitutions section caters to dietary preferences; print-friendly layout.
- **Visuals:** Infographic showing prep time vs. cook time improves readability.
- **Navigation:** Social sharing icons are prominently placed for virality.
